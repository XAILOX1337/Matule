# Подготовка к публикации в RuStore (Спринт 6)

Задание: создать приложение в яндекс-форме RuStore. Здесь — все материалы для формы и инструкция
по подписи релиза. Форму заполняет конкурсант сам, значения ниже копируются в неё.

## 1. Карточка приложения

| Поле формы | Значение |
|---|---|
| Название | `<фамилия латиницей>matule` — например `ivanovmatule` (требование КЗ) |
| Тип | Приложение, бесплатное (без покупок внутри) |
| Категория | Покупки |
| Возрастной рейтинг | 12+ (магазин, ввод персональных данных; насилия и 18+ контента нет) |
| Язык | Русский |

## 2. Краткое описание (до ~80 символов)

```
Matule — магазин схем для машинного вязания и дневник ваших проектов.
```

## 3. Полное описание

```
Matule — магазин описаний (схем) для машинного вязания.

Что умеет приложение:

• Каталог описаний. Схемы с примерным расходом пряжи и ценой. Поиск по названию
  и фильтрация по категориям: женщинам, мужчинам, детям, аксессуары.
• Акции и новости. Актуальные предложения на главном экране.
• Корзина и заказ. Добавляйте описания в корзину, меняйте количество
  и оформляйте заказ в один клик.
• Проекты. Ведите свои вязальные проекты: тип изделия, сроки, источник
  описания, фото готовой работы с камеры или из галереи.
• Быстрый вход. PIN-код или вход по биометрии — не нужно каждый раз
  вводить пароль.
• Работа без интернета. Главный экран доступен из кэша, а черновики
  проектов сохраняются на устройстве.

Matule — вяжите по проверенным схемам и не теряйте свои проекты.
```

## 4. Иконка

Готовая: `Matule/app/src/main/ic_launcher-playstore.png` (512×512, тот же «кит», что в приложении).

## 5. Скриншоты

Снимаются на эмуляторе (например, 1080×2400) — кнопка скриншота в панели Emulator.
Нужны все размеры «для смартфона» из формы. Список экранов (8–10 штук):

1. Заставка.
2. Вход и регистрация.
3. Главная (акции + каталог описаний).
4. Каталог с чипами категорий.
5. BottomSheet карточки описания.
6. Корзина.
7. Список проектов.
8. Создание проекта (заполненный).
9. Профиль.

## 6. Подпись релиза

`applicationId = ru.matule.app`, `versionCode = 1`, `versionName = 1.0` — уже заданы в
`Matule/app/build.gradle.kts`. Релиз без keystore подписывается debug-ключом (для тренировки),
для публикации нужен настоящий ключ:

```bash
# один раз, из папки Matule/
keytool -genkeypair -v -keystore keystore/matule-release.jks \
  -keyalg RSA -keysize 2048 -validity 10950 -alias matule
```

Затем создать `Matule/keystore.properties` (файл в `.gitignore`, в репозиторий не попадёт):

```properties
storeFile=keystore/matule-release.jks
storePassword=<пароль хранилища>
keyAlias=matule
keyPassword=<пароль ключа>
```

После этого `release` сам подписывается этим ключом:

```bash
./gradlew :app:assembleRelease   # APK
./gradlew :app:bundleRelease     # AAB для стора
```
