# Разбор макета «Matule 2026» (Figma)

Макет: <https://www.figma.com/design/pbwY6r5TtWUkxMsoJBWf0c/Matule-2026>

Файл открыт в режиме просмотра, без Inspect и Dev Mode, поэтому числа ниже — замеры по скриншотам:
размеры ±1–2 dp, цвета ±несколько единиц (JPEG). **Перед вёрсткой финальные значения сверять в Figma → Inspect.**
Скриншоты лежат в `docs/figma/`. Кружки с буквами на них — курсоры других зрителей файла, к макету они не относятся.

Макет нарисован под экран **375×812** (iPhone, статус-бар «9:41»), значит 1 px макета = 1 dp.

### 2.4. Замеры по экранам

## 4. Экраны

### Авторизация (скрин 00 — обзор)

1. **Заставка** (01): градиент — светло-голубые углы, насыщенный синий в центре; по центру белая надпись «Matule».
2. **Вход по паролю или биометрии** (01): заголовок «Вход», 4 точки PIN (заполненные — Accent), клавиатура 1–9, 0, ⌫. Кнопки круглые серые, нажатая синяя. Слот слева от 0 пустой.
3. **Вход и регистрация** (02, 03): «✋ Добро пожаловать!», «Войдите, чтобы пользоваться функциями приложения»; поле «Вход по E-mail» (example@mail.com); поле «Пароль» с глазом; «Далее» неактивна, пока поля пустые; ссылка «Зарегистрироваться»; «Или войдите с помощью»; «Войти с VK», «Войти с Yandex».
4. **Создание профиля** (04): «Создание Профиля»; «Без профиля вы не сможете создавать проекты. В профиле будут храниться результаты проектов и ваши описания.»; поля Имя, Отчество, Фамилия, Дата рождения, Пол (селект), Почта; «Далее» неактивна, пока не заполнено.
5. **Создание пароля профиля** (05): «✋ Создание пароля», «Введите новый пароль»; поля «Новый Пароль», «Повторите пароль» (оба с глазом); «Сохранить».
6. **Создание пароля = PIN** (06): «Создайте пароль», «Для защиты ваших персональных данных», 4 точки, клавиатура.

### Главная (08)
Поиск «Искать описания»; «Акции и новости» — горизонтальная карусель баннеров (цветной фон, название, цена, картинка:
«Шорты Вторник 4000 ₽», «Рубашка Воскресенье 8000 ₽»); «Каталог описаний» — чипы «Все / Женщинам / Мужчинам»;
список карточек товаров. Таббар, активна «Главная».

### Каталог (09, 10)
Поиск + иконка профиля справа; чипы категорий; карточки. После «Добавить» кнопка становится «Убрать»,
и над таббаром появляется плавающая «В корзину … ₽».

### Карточка описания — BottomSheet поверх каталога (09)
Заголовок «Рубашка воскресенье для машинного вязания» + «×»; «Описание» (длинный текст); «Примерный расход:» «80-90 г»;
кнопка «Добавить за 690 ₽».

### Корзина (11), без таббара
Хэдер: назад, «Корзина», удалить. Карточки Cart (название, «×», цена, «1 штук», − +); «Сумма 2490 ₽»;
кнопка «Перейти к оформлению заказа».

### Проекты (13)
«Проекты» + «+» справа; карточка «Мой первый проект», «Прошло 2 дня», «Открыть». Таббар, активна «Проекты».

### Создать проект (13)
Тип (селект «Выберите тип»), Название проекта («Введите имя»), Дата начала, Дата Окончания (маска),
Кому (селект «Выберите кому»), Источник описания («example.com»), Категория (селект «Выберите категорию»),
большая плитка «+» для фото, «Подтвердить».

### Профиль (12)
Имя «Эдуард», e-mail; пункты «Мои заказы» и «Уведомления» + Toggle (иконки похожи на эмодзи — сверить);
ссылки «Политика конфиденциальности», «Пользовательское соглашение», «Выход» (красный).

### В макете не нарисовано — собираем из компонентов UIKit
- BottomSheet со списком вариантов для селекта (со смайликами).
- BottomSheet выбора фото: «Галерея / Камера».
- Уведомление об успешном заказе (5 сек).
- Просмотр PDF политики и текст пользовательского соглашения.

## 5. Навигация

```
Заставка ──(есть сессия)──► Вход по PIN/биометрии ──► последний сохранённый экран (или Главная)
   └──(нет сессии)──► Вход и регистрация
                        ├─ «Далее» (авторизация OK) ──► Создание PIN ──► Главная
                        └─ «Зарегистрироваться» ──► Создание профиля ──«Далее»──► Создание пароля
                                                     ──«Сохранить» (регистрация + вход)──► Создание PIN ──► Главная

TabBar: Главная · Каталог · Проекты · Профиль
Главная/Каталог ─► Карточка описания (BottomSheet) ─► «Добавить за N ₽»
Каталог ─► «В корзину» ─► Корзина ─► «Перейти к оформлению» ─► уведомление 5 сек ─► Главная
Проекты ─► «+» ─► Создать проект ─► Проекты
Профиль ─► PDF политики / Соглашение ; «Выход» ─► Вход и регистрация
```
